# Ergo Basics

A visual, sourced introduction to the Ergo blockchain. Built with SvelteKit 2, Svelte 5, Vite, GSAP and Lenis, following the architecture used by `celaut-project.github.io`.

## Development

```sh
npm install
npm run dev
```

`npm run build` writes the static site to `build/`. English is served without a prefix; Spanish is prerendered under `/es/`.

Protocol claims should be checked against the primary sources linked on the site before publication. Ecosystem products and parameters can change independently of this repository.
